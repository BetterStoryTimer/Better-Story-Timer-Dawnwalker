# Better Story Timer Dawnwalker

**Better Story Timer Dawnwalker** is a quest clock pack for Blood of Dawnwalker. Pause the story timer, slow nights, skip wait. REFramework. Drop the zip in the mods folder.

## Getting Started
1. Download v1.1.0.
2. Extract `BetterStoryTimer.zip` next to REFramework.
3. Launch the game.
4. Insert opens the timer panel.

## FAQ

**What game?**
Blood of Dawnwalker on PC.

**REFramework?**
Required. This zip is the timer addon, not the framework.

**Does it break quests?**
Pause is safe for exploration. Do not freeze during timed scripted beats.

## Requirements
Windows 10/11. Blood of Dawnwalker + REFramework.
